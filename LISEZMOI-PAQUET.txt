composants puisent leurs reperes dans icones.css.


INSTALLATION

  Pour un projet qui demarre, une commande ecrit les fichiers de
  depart et installe la charte :

    npx https://chartegraphique-21.mtdpce-test.gov.bf/npm/govbf-create-charte-graphique-3.0.0.tgz

  Elle demande le dossier, le type de projet (statique, react,
  angular, laravel) et le depot npm interne s'il y en a un. Elle
  rappelle les conditions d'emploi et demande de les accepter avant
  d'installer quoi que ce soit ; sur une chaine d'integration,
  CHARTE_ACCEPTE_LICENCE=oui.

  Pour un projet deja commence :

    npm install https://chartegraphique-21.mtdpce-test.gov.bf/npm/govbf-charte-graphique-3.0.0.tgz

  L'archive est servie par le site de la documentation : l'espace
  de noms @govbf n'est encore sur aucun registre. Le paquet installe
  s'appelle @govbf/charte-graphique, et s'importe sous ce nom.

  Voir la page « Integration » de la documentation. En resume :

    import '@govbf/charte-graphique/css/tokens.css';
    import '@govbf/charte-graphique/css/faso.css';
    import '@govbf/charte-graphique/css/icones.css';
    import Faso from '@govbf/charte-graphique';

    Faso.observer();   // une fois, au demarrage de l'application

  Si le service propose le theme sombre, declarer aussi, dans
  <head> et avant la feuille de styles :

    <script src="/assets/js/faso-amorce.js"></script>

  Les libelles produits par le script sont rassembles dans
  Faso.textes, a completer avant l'initialisation si le service
  rend son interface dans une autre langue.

Sans chaine de construction, on sert les fichiers directement et
l'initialisation est automatique : il n'y a rien a appeler.


ARBORESCENCE A CONSERVER

Les declarations de polices designent les fichiers par un chemin
relatif, depuis assets/css/ vers assets/polices/. Deplacer l'un
sans l'autre casse le chargement : le texte bascule silencieusement
en police de repli, sans erreur.


CE QUE LA CHARTE PREND EN CHARGE, ET CE QU'ELLE LAISSE

  CSS seul                Boutons, cartes, encarts, badges, tableaux
                          statiques, filet, figures, graphiques,
                          composants metier.

  Comportement autonome   Modale, panneau, menu, accordeon, onglets,
                          depot de fichier, saisie de date,
                          calendrier, centre de notifications.

  Pilote par donnees      Tableau trie, filtre, pagine ;
                          autocompletion ; export.
                          -> Employer le CSS seul. Le cadriciel fait
                             la logique. Voir la page Integration.

Aucun composant React, Angular ou Vue n'est publie. Le motif de ce
choix est expose dans la documentation.

La page Integration traite en detail Angular, React et Laravel, et
renvoie les autres cadriciels a celui des trois dont ils se
rapprochent. Trois points y sont propres a un cadriciel :

  React     Les annonces se lisent par une reference et un ecouteur,
            non par une propriete onQuelqueChose.
  Angular   Les annonces portent un second nom a trait d'union,
            fs-onglet, seul liable dans un gabarit.
  Laravel   Avec Livewire, wire:ignore sur ce que la charte anime et
            wire:key sur ce qui se repete.

Pour Android, le CSS et le JavaScript ne s'executent pas : ce sont
les decisions qui se transportent. Le dossier android/ contient les
ressources produites depuis la meme feuille de jetons, en Kotlin et
en XML. En WebView, la charte s'execute telle quelle, a quatre
reglages pres decrits dans la documentation ; l'un d'eux compte
particulierement : refuser l'assombrissement automatique d'Android,
qui deplacerait le rouge, le vert et l'or officiels.


REFERENCE NORMATIVE

La charte applique le "Guide pour la definition de la charte
graphique des plateformes numeriques de l'administration publique",
du 10/08/2024, etabli par le Comite de suivi de la dematerialisation
des procedures administratives (MTDPCE/SG/DGTD) : couleurs
officielles du drapeau (rouge #EF2B2D, jaune #FCD116, vert #009E49),
Montserrat pour les titres et les boutons d'action, Roboto pour le
texte, palettes reservees aux espaces public et prive, structure
des pages. Ce qui n'en est pas applique tel quel est motive dans la
page Gouvernance de la documentation ("Ecarts assumes avec le
guide").

ACCESSIBILITE

Le systeme vise WCAG 2.1 AA. Les criteres relevant des composants
sont tenus par construction et verifies par la mesure la ou elle
est possible ; aucun audit externe n'a encore eu lieu. Ceux relevant
du projet — langue du document, textes de remplacement, hierarchie
des titres, libelles de liens — restent a sa charge. La liste figure dans la documentation.
